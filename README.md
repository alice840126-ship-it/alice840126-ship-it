## 지금 하는 일

- **브랜드 콘텐츠 운영 컨설팅** — 기업 채널의 꾸준한 노출을 위한 콘텐츠 전략과 운영
- **Blogkit** — 키워드 하나로 블로그 글·이미지·릴스 대본을 만드는 콘텐츠 자동 생성 서비스
- **GPTers 스터디장** — 현업의 자료와 반복 업무를 AI로 바꾸는 실무 중심 스터디
- **A&Shelter** — AI 상품 발굴부터 콘텐츠 제작, 판매채널 운영과 유통까지 직접 수행

---

## 일하는 방식

`강의와 기준 정리 → 현업 적용 → 운영·점검 → 다시 강의와 컨설팅에 반영`

AI를 설명하는 데서 멈추지 않고, 실제 업무에 연결한 뒤 지속 가능한 운영 방식으로 다듬습니다.
